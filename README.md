# Big-Three-Akinator

Упрощенная модель Акинатора, работающая на бинарной таблице признаков. 

Проект реализует алгоритмы машинного обучения, включая классификатор Random Forest из библиотеки scikit-learn и метрики векторного сходства, для анализа характеристик. Графический интерфейс построен с использованием Qt Creator. 

Программа умеет угадывать персонажей из «Большой тройки» сёнэнов (Naruto, Bleach, One Piece). Разработка ведется совместно с Футрук И.Ю.

---

## 1. Как скопировать репозиторий

Откройте терминал и выполните следующие команды для клонирования проекта на ваш компьютер:

```bash
git clone git@github.com:6ogdashka/Big-Three-Akinator.git
```

Перейдите в скачанную рабочую директорию:

```bash
cd Big-Three-Akinator
```

---

## 2. Установка Python

Для работы игры и запуска моделей машинного обучения необходим интерпретатор Python. Выберите вашу операционную систему:

*   **Windows:**
    Скачайте актуальную версию с официального сайта [python.org](https://www.python.org/). При запуске установщика обязательно поставьте галочку напротив **Add Python to PATH**.

*   **macOS:**
    Загрузите установочный пакет с официального сайта или установите через терминал с помощью Homebrew:
    ```bash
    brew install python
    ```

*   **Linux:**
    Используйте пакетный менеджер вашего дистрибутива. Например, для Arch Linux установка выполняется через pacman:
    ```bash
    sudo pacman -S python
    ```
    
    Для Ubuntu/Debian:
    ```bash
    sudo apt update && sudo apt install python3 python3-venv
    ```

---

## 3. Настройка виртуального окружения

Виртуальное окружение необходимо для изоляции библиотек проекта. В редакторе (например, VS Code или Code - OSS) этот процесс выполняется одинаково:

1.  Откройте встроенный терминал (нажмите `Ctrl + ~` или выберите в меню `Terminal -> New Terminal`).

2.  Создайте окружение командой:
    ```bash
    python -m venv venv
    ```
    *(Примечание: на macOS и некоторых дистрибутивах Linux может потребоваться команда `python3` вместо `python`)*

3.  Активируйте созданное окружение:
    
    *   **Windows**:
        ```cmd
        .\venv\Scripts\activate
        ```
        
    *   **macOS / Linux**:
        ```bash
        source venv/bin/activate
        ```

---

## 4. Загрузка требуемых библиотек

Убедитесь, что виртуальное окружение успешно активировано (в начале командной строки должен появиться префикс `(venv)`). 

Установите все необходимые зависимости с помощью файла `requirements.txt`:

```bash
pip install -r requirements.txt
```

---

## 5. Запуск

Когда все библиотеки загружены, запустите главный файл игры и бросьте вызов магии угадывания персонажей:

```bash
python gameUI.py
```
