Big-Three-Akinator
Упрощенная модель Акинатора, работающая на бинарной таблице признаков. Проект реализует алгоритмы машинного обучения, включая классификатор Random Forest из библиотеки scikit-learn и метрики векторного сходства, для анализа характеристик. Графический интерфейс построен с использованием Qt Creator. Программа умеет угадывать персонажей из «Большой тройки» сёнэнов (Naruto, Bleach, One Piece).
Разработка ведется совместно с Футрук И.Ю.
1. Как скопировать репозиторий
Откройте терминал и выполните следующие команды для клонирования проекта на ваш компьютер и перехода в рабочую директорию:
git clone git@github.com:6ogdashka/Big-Three-Akinator.git
cd Big-Three-Akinator

2. Установка Python
Для работы игры и запуска моделей машинного обучения необходим интерпретатор Python.
·	Windows: Скачайте актуальную версию с официального сайта python.org. При запуске установщика обязательно поставьте галочку напротив Add Python to PATH.
·	macOS: Загрузите установочный пакет с официального сайта или установите через терминал с помощью Homebrew:
·	brew install python

·	Linux: Используйте пакетный менеджер вашего дистрибутива (например, если вы используете Arch Linux с GNOME, установка выполняется через pacman):
o	Arch Linux: sudo pacman -S python
o	Ubuntu/Debian: sudo apt update && sudo apt install python3 python3-venv
3. Настройка виртуального окружения
Виртуальное окружение необходимо для изоляции библиотек проекта. В редакторе (например, VS Code или Code - OSS) этот процесс выполняется одинаково на любой операционной системе:
1.	Откройте встроенный терминал (Ctrl+` или через меню Terminal -> New Terminal).
2.	Создайте окружение командой:
3.	python -m venv venv

4.	(Примечание: на macOS и некоторых дистрибутивах Linux может потребоваться использовать python3 вместо python)
5.	Активируйте созданное окружение:
o	Windows: .\venv\Scripts\activate
o	macOS / Linux: source venv/bin/activate
4. Загрузка требуемых библиотек
Убедитесь, что виртуальное окружение активировано (в командной строке появится префикс (venv)), и установите все необходимые зависимости (scikit-learn, библиотеки Qt и другие) с помощью файла requirements.txt:
pip install -r requirements.txt

5. Запуск
Когда все зависимости установлены, запустите главный файл игры и бросьте вызов магии угадывания персонажей:
python gameUI.py
